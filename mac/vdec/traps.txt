# glue by tools/mac/mktraps.py (build/vd/toolbox_glue.s, toolbox_gen.h). TRAP/SELECTOR loads the selector
# into D0 before the trap. Trap words and selectors from QuickTime 2.5's interfaces (Universal Interfaces
# 2.1.4: Movies.h, Aliases.h, Folders.h, Files.h); register-based calls (the File and Memory Managers'
# parameter blocks) are in entry.s. Written on 23 November 2026 (docs/08 item 113).
#
