# The Toolbox calls the C programs in mac/ use: one line each, turned into C-callable glue
# (build/toolbox_glue.s) and prototypes (build/toolbox_gen.h) by tools/mac/mktraps.py.
#
#   trap result Name(type name:kind, ...)
#
# result and kind: l a long or pointer, w an INTEGER, b a BOOLEAN, c a CHAR, - none (result).
# Pascal calling convention: room for the result, the arguments pushed left to right, the trap;
# the trap pops the arguments and leaves the result on the stack.
#
