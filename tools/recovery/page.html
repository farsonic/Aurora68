Files on the SD card

    WiFi

    You are on the Pi's own access point, and the radio has only one network at a time: a test join would end it. Save your network, then restart: the Pi joins it at the next start. If the password was wrong, the Mac's screen says so; hold the interrupt button on the recovery screen again to come back here.

    Options

    Every option you may need, grouped, for the board chosen first: options another board uses are hidden (their values are kept). Changes only the options you edit; every other word in cmdline.txt is kept, and the line before is kept as cmdline.bak. The WiFi network is set on the WiFi tab.

      Run on the next start
      A one-shot debug start: the options chosen here go into debug-once.txt on the card. The next start adds them to cmdline.txt's and at once renames the file debug-once.old, so they are used once whatever that start does; the start after it is as cmdline.txt says, and the boot counter counts as always.
      

      

      Reports on the card
      The Pi has no clock: the kernel's own files carry no time, only their verdict.
        

        Report bundle
        One text file with the machine's summary (board, kernel, CPLD, memory, the options in effect), every report above and both logs, to send with an issue. WiFi passwords, tokens and the PIN are replaced by (hidden).
